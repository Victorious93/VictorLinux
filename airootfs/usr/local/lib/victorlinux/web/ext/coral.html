Edge TPU

Coral accelerator. Vision and wake words only.

A Coral Edge TPU runs small vision and wake-word models you provide. It cannot run chat models; those stay on the GPU or CPU. Off by default; nothing is downloaded.

Setup

Install the Edge TPU runtime (libedgetpu) and a TensorFlow Lite runtime yourself, then copy models compiled with edgetpu_compiler (*_edgetpu.tflite, labels in a matching .txt) into the coral folder.
